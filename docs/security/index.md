# Privacy & security

What JustTellMe keeps, where, and which permissions it needs. Up: [AGENTS.md](../AGENTS.md).

## Nothing leaves the Mac

Recognition runs locally (whisper.cpp). The app only goes to the network when you ask it to download something:
- a model, from `huggingface.co/ggerganov/whisper.cpp`;
- the Neural Engine encoder, from the same place.

No telemetry, no accounts.

## Data on disk

`~/Library/Application Support/JustTellMe/`:

| File | Contents | Removed by |
|---|---|---|
| `history.json` | Every dictation: text, time, language, app, length (max 2000) | «Очистить всё…» / «Удалить» on Главная |
| `dictionary.txt`, `replacements.txt` | Personal terms and fixes | Словарь page |
| `prompt.txt` | Custom prompt (only if changed) | «Подсказка по умолчанию» |
| `Models/` | Downloaded models and Core ML encoders | Finder (🎙 → Модель → «Открыть папку моделей») |

Settings are in `UserDefaults` (`com.justtellme.app`). Logs contain timings and errors, **never the dictated text**.

## Permissions

| Permission | Why |
|---|---|
| Microphone | Recording while you dictate |
| Accessibility | Listening for the dictation key (listen-only event tap) and sending ⌘V to paste |
| Login Items (optional) | Launch at login |

**Secure input:** while a password field (or Terminal's Secure Keyboard Entry) holds secure input, key presses don't reach us. Dictation still works, but Esc doesn't. The menu shows a warning naming the app that holds it.

## Clipboard

- The text goes on the clipboard as a lazy promise and is pasted with ⌘V.
- The previous clipboard is restored 0.25 s after the target app reads the text, or after 2 s at most. If you copied something in between, it is left alone.
- The item is marked `org.nspasteboard.TransientType`, `ConcealedType` and `AutoGeneratedType`, so clipboard managers skip it.

## Built-in dictionary

`Resources/builtin_terms.txt` and `builtin_replacements.txt` ship to everyone. They must not contain client or personal
names. A test fails if a banned name appears (it stores only their SHA-256 hashes).
